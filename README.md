# Muziko de nia tempo

Responsywny landing page odwzorowany z projektu Figma. Strona nie wymaga instalowania zależności ani procesu budowania.

## Uruchomienie

Otwórz `index.html` bezpośrednio w przeglądarce albo uruchom dowolny lokalny serwer HTTP w tym katalogu, np.:

```powershell
python -m http.server 8080
```

Następnie przejdź pod adres `http://localhost:8080`.
